## БГ-005 — Регистрация доступна при пустом обязательном поле «Номер телефона»

**Предусловия:**  
Пользователь не авторизован. Открыта форма регистрации. Все обязательные поля, кроме «Номер телефона», заполнены валидными данными.

**Шаги воспроизведения:**

1. Оставить поле «Номер телефона» пустым.
2. Заполнить остальные обязательные поля валидными данными.
3. Нажать «Зарегистрироваться».

**Ожидаемый результат:**  
Регистрация недоступна. Поле отмечается ошибкой, отображается сообщение о необходимости заполнить обязательные поля.

**Фактический результат:**  
Регистрация успешно выполняется с пустым номером телефона.

**Тип:** Functional / Validation

**Окружение:**  
Google Chrome, Firefox, web-приложение «Прилавок».

## БГ-012 — Элементы главной страницы перекрывают форму регистрации

**Предусловия:**  
Пользователь не авторизован. Открыта главная страница.

**Шаги воспроизведения:**

1. Открыть главную страницу.
2. Нажать «Зарегистрироваться».
3. Проверить отображение модального окна.

**Ожидаемый результат:**  
Форма регистрации отображается поверх затемненного фона. Элементы главной страницы не перекрывают модальное окно.

**Фактический результат:**  
Заголовки и другие элементы главной страницы отображаются поверх формы регистрации и перекрывают ее.

**Тип:** UI

**Окружение:**  
Google Chrome, Firefox, web-приложение «Прилавок».

## БГ-016 — При неверном пароле отображается некорректное сообщение

**Предусловия:**  
Пользователь зарегистрирован и не авторизован.

**Шаги воспроизведения:**

1. Ввести Email зарегистрированного пользователя.
2. Ввести неверный пароль.
3. Нажать «Войти».

**Ожидаемый результат:**  
Отображается сообщение:

`Неправильные логин и/или пароль`

**Фактический результат:**  
Отображается сообщение:

`Пользователь с такими данными не найден`

**Тип:** Functional / Validation

**Окружение:**  
Google Chrome, Firefox, web-приложение «Прилавок».
