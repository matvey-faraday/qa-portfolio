# Smoke checklist

Базовая проверка критически важной функциональности форм регистрации и авторизации приложения «Прилавок».

| ID | Проверка | Статус |
|---|---|---|
| SM-01 | Главный экран приложения открывается | Passed |
| SM-02 | Форма авторизации открывается по нажатию на кнопку «Войти» | Passed |
| SM-03 | Неавторизованный пользователь может открыть форму регистрации по кнопке «Зарегистрироваться» в шапке сайта | Passed |
| SM-04 | Неавторизованный пользователь может перейти к авторизации по кнопке «Войти» из шапки сайта | Passed |
| SM-05 | Пользователь может успешно авторизоваться с корректными Email и паролем | Passed |
| SM-06 | Пользователь может успешно зарегистрироваться при заполнении обязательных полей валидными данными | Passed |
| SM-07 | После успешной регистрации пользователь автоматически авторизуется и переходит на главную страницу | Passed |

## Результат

- Всего проверок: 7
- Passed: 7
- Failed: 0
- Blocked: 0

Smoke-тестирование показало, что основные критические сценарии доступны и продукт можно передавать на более глубокое функциональное тестирование.
